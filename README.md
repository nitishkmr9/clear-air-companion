# Clear Air Companion

Build a GenAI-powered web app "BreatheEasy" — an Urban Air Quality Assistant for families facing winter smog.

Features:

1. Live AQI dashboard — location-based air quality (PM2.5, PM10, AQI) with color-coded health status and hourly "best time to go outside" windows.

2. Family profiles — add members (child, elderly, runner) and their routines for tailored advice.

3. GenAI chat assistant — answers like "Can my kid play outside today?" using live AQI data, always explaining the direct impact of each choice.

4. Low-emission routine planner — daily plans with safe outdoor slots, pollution-avoiding routes, transit/carpool alternatives, and a "clean air score."

5. Indoor air hacks — ventilation timing, DIY purifiers, humidity tips, and indoor pollution reduction.

6. Impact tracker — shows CO₂ avoided, money saved, and health impact with charts and streaks.

Stack: React + Tailwind frontend, Node/Python backend, AQI API (OpenAQ/WAQI) + GenAI API.

Tone: calm, caring, non-alarmist — like a family health guide.
